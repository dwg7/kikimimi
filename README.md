# kikimimi(聞き耳)

公共ラジオ放送を「社会センサー」として使い、火山活動をめぐる社会の反応(報道量・
言及の文脈)をテレメトリするプロジェクト。第一の適用対象は**十勝岳**(北海道)。

## これは何か

気象庁・国土地理院の公式観測網(地震計、GNSS、傾斜計)は火山そのものを観測する。
kikimimiは、**火山をめぐる社会の反応**——公共ラジオがどれだけの頻度で、どんな
文脈で言及しているか——を、補完的なレイヤーとしてテレメトリする。報道量の
時系列変化そのものが、公式観測データだけでは掴めない、社会の受け止め方の推移
という独自の信号になる、という考え方に立っている。

[yuiseki/OpenSpeechMap](https://github.com/yuiseki/OpenSpeechMap)(MIT License)を
土台に、[Open MCT](https://github.com/nasa/openmct)でダッシュボード化する。

## 重要な留保

**これはverified intelligenceではない。** 状況認識のための補助的なsignalで
あり、確定した事実でも、気象庁の噴火警戒レベル・警報等の公式判断の代替でも
ない。検出結果を見る際は、必ずこの留保とともに読んでほしい。誤検出はゼロには
ならない。ここで拾われた候補は「見に行く理由」であって「結論」ではない。

## 位置づけ

十勝岳の対応にあたる北海道地方測量部を、dwg7の観点から外部支援するプロジェクト。
GSIの公式対応の指揮系統を代替・介入するものではなく、その外側から軽量・機動的な
補助線を提供する立場に徹する。
